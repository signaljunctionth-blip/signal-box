# ภารกิจสายอีสาน (M5 / WP8)

ข้อมูลจริงอยู่ที่ `data/levels/isan.json` เทสต์คือ `test/isan-test.mjs` (อยู่ใน `npm run test:sim`)
ผัง: `data/stations/buri-ram.json`, `surin.json`, `thanon-chira-jn.json` ตารางเดินรถทั้งหมดเป็นของสมมุติ

## หลักที่ใช้
- เพิ่มความยากด้วยขบวนสินค้าและลำดับความสำคัญ (`priority`) ไม่เพิ่มราง (เงื่อนไขเจ ข้อ 4)
- ไม่มีห่วงทางสะดวกในสายนี้ (เงื่อนไขเจ ข้อ 5) เทสต์ตรวจว่าไม่มี `token`
- ขา K ของบุรีรัมย์ (ทางแยกเขากระโดง) เป็นทางแยกสมมุติ ใช้กับขบวนสินค้าเท่านั้น เทสต์ตรวจให้
- ขั้น 3 (บุรีรัมย์ สุรินทร์) ใช้ยุคไฟสีและวงจรตอนราง ผู้เล่นสับประแจเอง ขั้น 4 (ถนนจิระ) ใช้ยุค NX
- แต่ละสถานีไล่: ต้นทาง/ปลายทาง หรือสินค้าแบบง่าย → สินค้าเข้าทางสินค้า → หลบสินค้าให้ด่วน → ภารกิจรวม (ข้อสอบ มี `maxWait`)
- ยังไม่มีการ์ด "รู้หรือไม่" นักเขียนบทสอนทำต่อ

## เหตุผลความยาก
- บุรีรัมย์ 3 ทาง สุรินทร์ 4 ทาง ใกล้วังโพ ความยากจึงมาจากขบวนสินค้าที่ช้า (0.7×) ยาว (1.5×) และกินตอนทางเดี่ยวนาน ผู้เล่นต้องคิดว่าจะปล่อยสินค้าเมื่อไร
- สุรินทร์มีประแจ 3 ตัวต่อคอสถานีถึงทาง 4 ต้องแตะหลายครั้ง จึงให้ผ่อนรอ (`waitGrace`) มากกว่าบุรีรัมย์
- priority ทำให้ด่วนรอเสียคะแนน 2 เท่า สินค้าครึ่งเดียว บทเรียน "กักสินค้าไว้ก่อน" จึงเห็นเป็นคะแนน
- ถนนจิระยุค NX แตะน้อยกว่า ความยากมาจากทางขัดกัน (ผังหลังแก้ทางข้ามตาม OSM): ทาง 1/2 ไปได้แค่ขา B, ขา C ไปได้จากทาง 3 และย่านสินค้าเท่านั้น, ทาง 3 ไปขอนแก่นต้องผ่านทางข้าม xo ที่ขัดกับสายอุบลฯ, ขบวนสินค้าออกจากย่านใช้ทางสายอุบลฯ ร่วม และขานครราชสีมาที่ทุกขบวนใช้ร่วม
- ขบวนสินค้าเข้าย่านแล้วกลับทิศทันที ข้อความเขียนว่า "ในเกมนี้" (ของจริงต้องสลับหัวรถจักรหรือมีหัวรถจักรสองปลาย)
- ข้อสอบตั้งผ่อนรอต่ำ (6–12) และมีเวลารอสูงสุด เพื่อให้บอทตามคำใบ้ต่ำกว่า 80% แต่ยังได้ 3 ดาวถ้าจัดลำดับเป็น

## เกณฑ์ดาวและการปลดล็อก
- ดาวใช้เกณฑ์เดียวกับสายน้ำตก (`MISSIONS-NAMTOK.md` ข้อ 4): 1 ดาว = จบ, 2 ดาว ≥ 55%, 3 ดาว ≥ 80%
- ภารกิจในสถานีเดียวกันเปิดตามลำดับ สถานีถัดไปเปิดเมื่อผ่านทุกภารกิจของสถานีก่อนหน้าและดาวสะสมถึง `needStars`

| สถานี | ขั้น | ภารกิจ | needStars | ดาวเต็มก่อนถึง | สัดส่วน |
|---|---|---|---|---|---|
| บุรีรัมย์ | 3 | br-1..4 | 0 (เปิดพร้อมหน้าเลือกสาย) | – | – |
| สุรินทร์ | 3 | sr-1..4 | 6 | 12 | 50% (แบบกาญจนบุรี 15/30) |
| ชุมทางถนนจิระ | 4 | tc-1..4 | 15 | 24 | 62% (แบบหนองปลาดุก 24/39) |

ผ่านทุกภารกิจแค่ 1 ดาว (8 ดาว) ยังเข้าถนนจิระไม่ได้ ต้องเก็บ 3 ดาวภารกิจง่ายเพิ่ม (เทสต์ตรวจ)

## ถ้าแก้ตาราง
- id ภารกิจ (`br-1`..`tc-4`) ห้ามเปลี่ยน เป็น key เซฟ
- แก้ตารางของ br-3, br-4, sr-4, tc-3, tc-4 แล้วต้องหาแผนใน `PLANS` ของเทสต์ใหม่ (สุ่มค้นแผนกักขบวนนอกเทสต์)
- ถ้าเจลองแล้วยากไป ปรับ `waitGrace` หรือ `maxWait` ของข้อสอบก่อน ไม่ต้องแตะตาราง
