# แผนพัฒนา (Milestones)

แต่ละขั้นจบเมื่อผ่าน "เกณฑ์รับงาน" ทุกข้อ และเจลองเล่นแล้วตอบรับ ทำทีละขั้น ห้ามข้าม

## M0 ตั้งโปรเจกต์ (ครึ่งวัน)
- สร้างโครง Vite + JavaScript (ES modules) ผลลัพธ์ build ไปที่ `dist/` แล้ว deploy ขึ้น GitHub Pages ผ่าน GitHub Actions (ฟรี)
- ย้ายต้นแบบ v2 ไป `prototype/` และให้เปิดเล่นได้ที่ `/prototype/`
- เผื่อการห่อเป็นแอปภายหลัง: path แบบ relative ทั้งหมด (`base: './'`), ฝังฟอนต์ Mitr + Anuphan ในเกมพร้อมไฟล์ OFL (ไม่ดึงจาก Google Fonts ตอนเล่น)
- เกณฑ์: `npm test` ผ่าน, `npm run build` ผ่าน, ลิงก์ GitHub Pages เปิดได้, เปิด `dist/` จากโฟลเดอร์ย่อยแล้วยังเล่นได้

## M1 เอนจินอ่านผังจาก JSON + ขบวนสองทิศ
- แยกโค้ด v2 เป็นโมดูล: `sim/` (ราง, อินเตอร์ล็อก, ขบวน), `render/` (canvas แนวนอนอย่างเดียว ตัดโค้ดผังแนวตั้งของ v2 ออก), `ui/` (หมุนทั้งเวทีเมื่อถือเครื่องแนวตั้ง)
- โหลดผังจาก `data/stations/*.json` แทน `LAYOUTS` ที่เขียนในโค้ด
- ขบวนเข้า-ออกได้ทั้งสองฝั่ง, สัญญาณทั้งสองทิศ
- เซฟเกมผ่านโมดูลเดียว (`save/`) เพื่อสลับที่เก็บได้เมื่อห่อเป็นแอป, หน้าจอเผื่อขอบจอ (safe area) ของมือถือ
- เกณฑ์: 12 ด่านเดิมเล่นได้เหมือนเดิมด้วยผังจาก JSON, บอทผ่านทุกด่าน, มีด่านทดสอบรถสวนทาง

## M1.5 ต้นแบบภาพ 3 มิติ (ทดลองก่อนตัดสินใจเดินหน้า)
- ฉาก 3 มิติของสถานีเดียว (ท่ากิเลน) ด้วย Three.js: ราง ประแจ สัญญาณ ชานชาลา ขบวน สร้างด้วยโค้ดจากไฟล์ผัง JSON เดียวกับแผง 2 มิติ
- แตะสัญญาณ/ประแจในฉาก 3 มิติได้ (เป้าแตะ ≥ 40 px) และปุ่มสลับ 3 มิติ ↔ แผงผังเส้น
- ผ่าน `legal-guard` (สัญญาอนุญาตไลบรารี ไม่มีโมเดลจากภายนอก)
- เกณฑ์: มือถือระดับกลางได้ 30 เฟรม/วินาทีขึ้นไปที่ 844×390, โค้ดและไลบรารีเพิ่มไม่เกิน 1 MB (ชิ้นงาน CC0 นับแยกตามเพดานใน `docs/LEGAL-AND-COST.md`), บอทยังผ่านทุกด่าน, เจดูแล้วตอบรับว่าเหมือนจริงพอ ถ้าไม่ผ่านเกณฑ์ความเร็ว ให้หยุดและเสนอทางเลือกกับเจ

## M2 ห่วงทางสะดวก + หลีกขบวน (ขั้น 1–2)
- ตอนบล็อกระหว่าง 2 สถานี ใช้ห่วง 1 อัน: ขบวนต้องมีห่วงถึงเข้าตอนได้ (เกมแสดงห่วงเป็นวงกลมสีเหลืองที่สถานี/บนขบวน)
- ภารกิจหลีกขบวนที่สถานีมีทางหลีก
- เกณฑ์: บทสอนสถานีแรกจบได้ใน 3 นาที, เด็ก ม.ปลายที่ไม่รู้เรื่องรถไฟเล่นผ่านได้ (เจหาคนลอง 2–3 คน)

## M3 แผนที่ประเทศไทย + เส้นทางสอน
- `tools/build-map.mjs` สร้าง `data/thailand-map.json`
- หน้าแผนที่: ซูม/เลื่อนด้วยนิ้วและเมาส์, สถานีที่ปลดล็อก/ล็อก, ข้อความ OSM
- แตะสถานีที่ผ่านแล้วเพื่อกลับเข้าไปเล่นซ้ำ เห็นดาวที่ดีที่สุดของแต่ละภารกิจ
- สร้างสถานีสายน้ำตก 5 แห่งตาม `docs/STATIONS.md` ด้วย skill `/new-station`
- เกณฑ์: แผนที่โหลดเร็ว (ไฟล์แผนที่ < 1.5 MB), เครดิตครบ

## M4 งบประมาณ อัปเกรด และโหมดสร้าง
- ระบบงบประมาณ ดาว ปลดล็อก
- อัปเกรดระบบสัญญาณต่อสถานี (หลักเขต → หางปลา → ไฟสี+รีเลย์ → CBI)
- ตัวแก้ผังบนกริด + ตารางอินเตอร์ล็อกที่สร้างอัตโนมัติ
- แชร์ผังด้วยรหัสและลิงก์ (ข้อมูลอยู่ในลิงก์ ไม่มีเซิร์ฟเวอร์) ผังที่รับมาต้องผ่านตัวตรวจผังก่อนเล่น
- เกณฑ์: สร้างทางหลีกใหม่ในสถานีแล้วเล่นได้จริง, ตารางอินเตอร์ล็อกถูกต้องตามที่ `signalling-engineer` ตรวจ, แชร์ผังจากมือถือไปเปิดเล่นบนคอมได้, รหัสผังที่เสียหรือถูกแก้ไม่ทำให้เกมพัง

## M5 สถานีจังหวัดและชุมทาง + เลือกสาย
- สายแรกตามลำดับประวัติศาสตร์ (สายอีสาน ช่วงกรุงเทพ–นครราชสีมา หลังตรวจปีเปิดเดินรถกับแหล่งอ้างอิงแล้ว) อย่างน้อย 2 สถานีจังหวัด + 1 ชุมทาง สายถัดไปทำตามลำดับใน `docs/STATIONS.md`
- ขบวนด่วน ขบวนสินค้า ลำดับความสำคัญ
- หน้าเลือกสาย 6 สาย (อีสาน, เหนือ, ใต้, แม่กลอง, ตะวันออก, ตะวันตก) สายที่ยังไม่มีสถานีแสดงว่า "เร็ว ๆ นี้"
- เกณฑ์: ผู้เล่นเลือกสายเองได้หลังผ่านการสอนเล่น และปลดล็อกสถานีไล่ไปตามสายได้

## M6 แขวงการเดินรถ
- หน้าแขวง: 4–8 สถานีเรียงกัน ใช้ผังย่อ, เวลาเดินระหว่างสถานี, จุดหลีกทั้งสาย
- เกณฑ์: แขวงแรกเล่นได้ทั้งบนมือถือ (844×390) และคอม

## M7 ศูนย์ควบคุม CTC
- ผังทั้งสาย, ARS ตั้งทางอัตโนมัติ (ผู้เล่นแก้เมื่อระบบตัดสินใจผิด), ETCS L1 แบบง่าย (จำกัดความเร็วตามสัญญาณ), เหตุขัดข้อง (ประแจค้าง, ตอนรางแจ้งรถทั้งที่ไม่มีรถ)
- เกณฑ์: เล่นจบ 1 ภารกิจ CTC ได้ภายใน 15 นาที

## M8 ขัดเกลาและปล่อย
- เสียง Web Audio, มาสคอต, ความสำเร็จ (achievements), PWA เล่นออฟไลน์
- โหมดอัดคลิป 1080×1920 สำหรับทำคอนเทนต์ TikTok: วางแผงเกมแนวนอนไว้กลางกรอบแนวตั้ง มีที่ว่างบน-ล่างสำหรับหัวเรื่องและคำบรรยาย (เกมยังเล่นแนวนอนเหมือนเดิม)
- ลิงก์จากเว็บ Signal Junction Club
- เกณฑ์: ผ่านเช็กลิสต์ใน `docs/LEGAL-AND-COST.md` ส่วน E

## M9 ออนไลน์: กระดานคะแนน + คลังผัง
- กระดานคะแนนต่อภารกิจและต่อผังที่แชร์ ผ่าน Google Apps Script ของช่อง (โควตาฟรี) เก็บแค่ชื่อเล่นกับคะแนน มีตัวกรองคำหยาบ
- คลังผังของชุมชน: ส่งผังเข้าคลัง เจอนุมัติก่อนแสดง
- เกมต้องเล่นได้ปกติเมื่อออฟไลน์หรือ Apps Script ล่ม
- ต้องผ่าน `legal-guard` (PDPA, โควตา, ไม่มีค่าใช้จ่าย)
- เกณฑ์: ส่งคะแนนและเห็นอันดับได้จาก 4 อุปกรณ์, ปิดเน็ตแล้วเกมไม่ค้าง

## M10 แอปติดตั้ง (ต้องให้เจอนุมัติค่าใช้จ่ายก่อนแต่ละขั้น)
- PC: ห่อด้วย Tauri แจกบน itch.io (ฟรี)
- Android: ห่อด้วย Capacitor ขึ้น Google Play (มีค่าสมัคร)
- iOS: ห่อด้วย Capacitor ขึ้น App Store (มีค่าสมัครรายปี)
- เกณฑ์: โค้ดเกมชุดเดียวกับเว็บ ไม่แตกสาขา

## หลัง M10 (ไอเดีย)
- โหมดประวัติศาสตร์เพิ่มยุคไทย (เช่น การเปิดทางคู่สายต่าง ๆ)
- ร่วมกับโปรเจกต์ Thai-Train-Station-Sim (กรุงเทพอภิวัฒน์) เป็นฉากพิเศษ
