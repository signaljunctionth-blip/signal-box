# แผนแบ่งงานเป็นชุด (สำหรับเปิดแชทใหม่ทีละงาน)

เจเปิดแชทใหม่ 1 แชทต่อ 1 ชุดงาน แล้ววาง "ข้อความเริ่มงาน" ของชุดนั้น เมื่อชุดหนึ่งเสร็จ (ผ่านเกณฑ์จบ) จึงเริ่มชุดที่ขึ้นต่อกันได้
อัปเดตล่าสุด: 2026-10-17

## กติการ่วมของทุกชุด (กันงานชนกัน)
1. **หนึ่งแชทหนึ่งชุดงาน** และแต่ละแชททำใน branch ของตัวเอง ชื่อตามรหัสชุด เช่น `wp2-portrait` แตกจาก `main` ล่าสุด ถ้าเปิดได้ ให้ทำใน worktree แยกโฟลเดอร์ (แอป Claude สร้างให้ตอนเปิดแชทใหม่) ห้ามสลับ branch ในโฟลเดอร์ที่แชทอื่นใช้อยู่
2. **ชุดที่แก้ `src/sim/` ทำได้ทีละชุดเท่านั้น** (WP3, WP4, WP7 ห้ามทำพร้อมกัน) ชุดอื่นทำคู่ขนานได้ตามตาราง
3. ทุกชุดต้องผ่าน `npm test` และผู้ตรวจตาม CLAUDE.md (`qa-tester` สำหรับโค้ด, `legal-guard` สำหรับข้อมูล/ภาพ/บริการภายนอก, `signalling-engineer` สำหรับกติกาและผังราง)
4. จบชุดด้วย PR เข้า `main` หนึ่ง PR เจเป็นคนสั่ง merge merge แล้วเกมออนไลน์อัปเดตเอง
5. ห้าม push branch `main` เก่าในเครื่อง (มีข้อมูลส่วนตัวในประวัติ) และห้าม `git push --all`
6. การตัดสินใจใหม่ของเจ ให้บันทึกในเอกสารที่เกี่ยวข้อง (`docs/GDD.md`, `docs/SIGNALLING-RULES.md`, `docs/ART-3D.md`) ภายใน PR ของชุดนั้น

- **แตะไฟล์:** `src/ui/`, `src/render/` (เฉพาะ 2 มิติ), `index.html`, `src/style.css`, `test/`
- **ห้ามแตะ:** `src/sim/`, `data/`
- **งาน:** หมุนทั้งเวที 90° เมื่อถือเครื่องแนวตั้ง (ตาม CLAUDE.md) และแปลงพิกัดแตะให้ตรง, safe area ของจอมีรอยบาก, ปุ่มเต็มจอ, บั๊กหน้าจอที่ qa-tester ของ WP1 รายงานว่ายังเหลือ
- **ผู้ตรวจ:** qa-tester (390×844, 844×390, 1180×820, 1280×800 สว่าง/มืด)
- **เกณฑ์จบ:** ตามเกณฑ์ M1 ใน ROADMAP และเล่นได้บนมือถือเครื่องจริงของเจทั้งถือตั้งและถือนอน
- **ข้อความเริ่มงาน:**

## WP5 สีเส้นทางตามป้ายข้างขบวนรถ
- **ขึ้นกับ:** ไม่มี (ค้นคว้าทำได้ทันที ส่วนแก้สีในโค้ดทำหลัง WP1)
- **แตะไฟล์:** `src/style.css` (ตัวแปร `--ln-*` เท่านั้น), `data/sources.md`, `docs/GDD.md` ข้อ 5
- **ข้อมูลตั้งต้นจากเจ (ยังไม่มีแหล่งสาธารณะยืนยัน):** ป้ายข้างขบวนรถ สายเหนือฟ้า สายอีสานเขียว สายใต้เหลือง ขบวนชานเมืองแดง เจอนุญาตให้ใช้โทนพาสเทลของสีจริง ผลค้นรอบแรกไม่พบระบบสีประจำสายในแผนที่ ตาราง และป้ายสถานีของ รฟท. การค้นป้ายข้างรถหยุดกลางทางเพราะโควตาหมด
- **งาน:** หาภาพป้ายข้างรถจริงที่เผยแพร่สาธารณะยืนยันสีทีละสาย หาสีสายตะวันออก แม่กลอง และขบวนสายน้ำตก/สุพรรณบุรี แล้วทำชุดสีพาสเทล 6 สายที่อ่านได้ทั้งโหมดสว่าง/มืดและแยกได้สำหรับผู้ตาบอดสี
- **ผู้ตรวจ:** legal-guard (แหล่ง), qa-tester (การอ่านบนแผนที่)
- **ข้อความเริ่มงาน:**
  > ทำชุดงาน WP5 ใน docs/WORK-PACKAGES.md อ่าน CLAUDE.md และกติการ่วมในไฟล์นั้นก่อน เริ่มจากค้นคว้า ยังไม่แก้โค้ดจนกว่า WP1 จะ merge แล้ว

## WP6 เตรียมสายแรกตามประวัติศาสตร์ (สายอีสาน)
- **ขึ้นกับ:** ไม่มี (ค้นคว้า ไม่แตะโค้ด)
- **แตะไฟล์:** `docs/STATIONS.md`, `data/sources.md`, `data/raw/` (ไฟล์ OSM ใหม่)
- **งาน:** หาปีเปิดเดินรถของทั้ง 6 สายพร้อมแหล่งอ้างอิง เพื่อยืนยันลำดับสร้าง (ตอนนี้ อีสาน → เหนือ → ใต้ → แม่กลอง → ตะวันออก → ตะวันตก ยังไม่ได้ตรวจ), ตรวจว่าทางแยกใดยังเดินรถ, สำรวจ OSM ของสายแรกเพื่อเลือก 2 สถานีจังหวัด + 1 ชุมทาง พร้อมตัวเลือกให้เจเลือก (แบบเดียวกับที่ทำกับสายน้ำตก)
- **ผู้ตรวจ:** legal-guard, signalling-engineer
- **ข้อความเริ่มงาน:**
  > ทำชุดงาน WP6 ใน docs/WORK-PACKAGES.md อ่าน CLAUDE.md, docs/STATIONS.md, docs/DATA-PIPELINE.md และกติการ่วมในไฟล์นั้นก่อน งานนี้ค้นคว้าอย่างเดียว ไม่แก้โค้ด

- **ผู้ตรวจ:** game-designer, signalling-engineer, qa-tester
