# สรุปการตัดสินใจของเจ (อ่านไฟล์นี้แทนเอกสารยาว)

ไฟล์สั้นสำหรับทุกแชทและทุกเอเจนต์ อ่านเอกสารยาวเฉพาะหัวข้อที่งานต้องใช้จริง ถ้าขัดกัน ให้ถือไฟล์นี้ แล้วแจ้งผู้อำนวยการเกมให้แก้เอกสารยาว
อัปเดตล่าสุด: 2026-10-18

## เกมและแพลตฟอร์ม
- ชื่อเกม **Signal Junction** (อังกฤษอย่างเดียว) โหมดประวัติศาสตร์และเกมเวอร์ชันเดิมใน `prototype/` ใช้ชื่อ "ห้องสัญญาณ 200 ปี"
- ลิงก์: https://signaljunctionth-blip.github.io/signal-junction/ repo สาธารณะ `signaljunctionth-blip/signal-junction`
- เว็บก่อน แล้ว PWA แล้วแอป PC/Android/iOS (ค่าสมัครสโตร์ต้องให้เจอนุมัติ)
- เล่นคนเดียว ออนไลน์เฉพาะกระดานคะแนนและแชร์ผัง
- เล่นแนวนอนทุกอุปกรณ์ ถือแนวตั้งให้หมุนทั้งเวที
- เกมเวอร์ชันเดิมแยกเก็บถาวร ไม่แก้ตรรกะ

## ความก้าวหน้าของผู้เล่น
- เส้นทางสอนสายน้ำตก: ท่ากิเลน → วังโพ → น้ำตก (ปลายทาง) → กาญจนบุรี → ชุมทางหนองปลาดุก
- หลังสอน ผู้เล่นเลือกสายเอง 6 สาย ทีมสร้างตามลำดับประวัติศาสตร์ เริ่มสายอีสาน (ลำดับยังไม่ได้ตรวจแหล่ง)
- สถานีสอน 5 แห่งนับเป็นความคืบหน้าของ "สายตะวันตก" ซึ่งเป็นการจัดกลุ่มของเกม (รฟท. นับเป็นทางแยกของสายใต้)
- เล่นซ้ำได้ งบจากการเล่นซ้ำได้เฉพาะส่วนที่ดีกว่าเดิม

## คำศัพท์และกติกาสัญญาณ
- เที่ยวขึ้น = วิ่งออกจากกรุงเทพ, เที่ยวล่อง = วิ่งเข้าหากรุงเทพ (โค้ดใช้ E/W และ `upDir`)
- เสาเข้า, เสาออก, หลักเขตปลอดภัย, ทางเผื่อหยุดเลย, ประแจปลายไกล, คำกริยา "สับประแจ"
- ชื่อเสา: ตัว S ทุกต้น ปลายสถานีด้านขาล่องเลขคี่ ด้านขาขึ้นเลขคู่ นับจากนอกเข้าใน เสาเข้าได้เลขน้อยสุด แล้วเสาออกเรียงตามเลขทาง (เกมตั้งเอง ต้องบอกผู้เล่น) ใช้ผ่าน `label`
- เสาอยู่ด้านซ้ายของคนขับเสมอ
- "รถฝ่าประแจ" แยกจาก "ตกราง"
- รับขบวนสองขาพร้อมกันได้เมื่อทางเผื่อหยุดเลยไม่ทับกัน ข้อความห้ามอ้างว่ารับทีละขบวนเสมอ
- ประแจปลายไกลบนทางเผื่อหยุดเลย: ยุคอินเตอร์ล็อกกลผู้เล่นสับเอง ยุคไฟสี/คอมพิวเตอร์ระบบตั้งให้
- ยุคอินเตอร์ล็อกกลคงการตรวจรางว่าง แต่ข้อความบอกว่า "เจ้าหน้าที่เห็นว่า..."
- ห่วงทางสะดวก (M2): เครื่องทางสะดวกสองปลายตอน ออกห่วงได้ทีละอัน
- กติกาที่เป็นการทำให้ง่าย ข้อความต้องเขียนว่า "ในเกมนี้"
- รายละเอียดเต็ม: `docs/SIGNALLING-RULES.md` (ยาว อ่านเฉพาะหัวข้อที่ใช้)

## ภาพและแบรนด์
- **เจต้องการให้เป็น 3 มิติทั้งเกม พร้อมกล้องอิสระ** (2026-10-19 หลังลองโหมด 3 มิติที่ท่ากิเลน) งานอยู่ใน WP10 ผังเส้น 2 มิติยังสลับได้เสมอ
- ฉากสถานีเป็น 3 มิติแนวเหมือนจริงแบบเรียบ เป้าภาพคือภาพแนวคิดรุ่น 2.1 https://claude.ai/artifact/PR24okCEdDVjeQTRAWGbN6 สลับเป็นผังเส้น 2 มิติได้เสมอ
- สายแดดดีมีเมฆ, ตัวถังขบวนสีธรรมชาติ ใช้สีแบรนด์เป็นแถบคาด, โหมดมืดเป็นพลบค่ำ
- ใช้ชิ้นงาน CC0 ได้เฉพาะโมเดล 3 มิติ พื้นผิว ภาพท้องฟ้า และต้องผ่าน legal-guard ทีละชิ้น (ผ่านแล้ว 11 ชิ้น ยังไม่นำเข้า) รายละเอียด: `docs/ART-3D.md`
- สีเส้นทางบนแผนที่อิงป้ายข้างขบวนรถ ใช้โทนพาสเทลได้ เจจำได้ว่า เหนือฟ้า อีสานเขียว ใต้เหลือง ชานเมืองแดง (ยังไม่มีแหล่งยืนยัน) ตอนนี้ใช้พาสเทลเดิมชั่วคราว
