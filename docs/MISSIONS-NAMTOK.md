## 1. ข้อตกลงที่ใช้ทั้งเอกสาร

- **ฝั่ง:** ซ้ายของแผง = `W` = ด้านกรุงเทพ/ชุมทางหนองปลาดุก ขวา = `E` = ด้านน้ำตก ทุกผัง `upDir: "E"` (เที่ยวขึ้น = ออกจากกรุงเทพ) ข้อความที่ผู้เล่นเห็นใช้ "เที่ยวขึ้น/เที่ยวล่อง" ชุมทางหนองปลาดุก: ขา `A` ด้านกรุงเทพ (ซ้าย) ขา `B` สายใต้ และขา `C` สายน้ำตก (ขวาทั้งคู่)
- **ทาง:** ป = ทางประธาน (`main`), ล1/ล2 = ทางหลีก (`loop1`, `loop2`), ต = ทางตัน (`bay1`), ท1–ท3 = ทางจอดที่ชุมทาง (`t1`–`t3`)
- **ชนิดขบวน:** ธรรมดา (จอด 2.5 วิ), ด่วน (ผ่านไม่จอด), กลับหัว (จอดแล้วออกขาเดิม)
- **เวลาในตาราง:** ตัวเลข = วินาทีที่ขบวนโผล่ "หลัง n +d" = มาหลังขบวน n พ้นจอ d วินาที ถ้ามาจากขาเดียวกับที่ขบวน n เพิ่งออกไป จะช้ากว่านั้นอีกราว 16 วิ (ตอนยังไม่ว่าง 8 วิ + วิ่ง 8 วิ)
- **เลขขบวน:** เลขที่ผู้เล่นเห็นคือลำดับในตาราง (1, 2, 3…) ไม่ใช่เลขขบวนจริง ข้อความในภารกิจจึงไม่อ้างเลขขบวน และยังทำให้เที่ยวขึ้นเป็นเลขคี่ทุกภารกิจไม่ได้ (เช่น น้ำตกทุกขบวนเป็นเที่ยวขึ้น) ถ้าต้องการต้องมีฟิลด์เลขขบวนแยกจากลำดับ
- **คำที่ผู้เล่นเห็น:** เสาเข้า เสาออก รถฝ่าประแจ ตาม `docs/SIGNALLING-RULES.md`
- **คะแนน:** เข้าทางถูก 100, เข้าผิดทาง 20, ออก 50, ด่วนผ่านไม่ต้องหยุด 150 (ต้องหยุดที่ทางจอด 60), รอเกิน `waitGrace` −3 คะแนน/วิ คะแนนเต็ม = 150 × จำนวนขบวน
- **ขบวนไหนเข้าทางหลีก:** ตารางกำหนดเอง ในเกมนี้ขบวนจอดเข้าทางหลีก ขบวนผ่านใช้ทางประธาน

ชุดกติกา (`eras` ในชุดด่าน):

| era | ใช้กับ | interlock | sema | tc | nx |
|---|---|---|---|---|---|
| 0 | ขั้น 1 ท่ากิเลน | false | true | false | false |
| 1 | ขั้น 2 วังโพ น้ำตก | true | true | false | false |
| 2 | ขั้น 3 กาญจนบุรี | true | false | true | false |
| 3 | ขั้น 4 หนองปลาดุก | true | false | true | true |

### กติกาเขียนตารางขบวน (ได้จากการรันบอท ใช้กับภารกิจใหม่ทุกอัน)

1. **ขบวนที่เข้าจากขา X ห้ามกำหนดให้จอดทางที่ผู้ใช้คนก่อนจะออกไปขา X** ขบวนใหม่ยึดตอนทางเดี่ยวของขา X ไว้ คันเก่าออกไม่ได้ คันใหม่ก็เข้าไม่ได้ ยกเว้นขบวนใหม่มาแบบ "หลัง" คันเก่าพ้นจอ (เทสต์ตรวจข้อนี้ให้) ผลคือสถานีทางเดี่ยวใช้ทางตามทิศ: เที่ยวขึ้นเข้าทางหลีก เที่ยวล่องใช้ทางประธาน
2. **ขบวนในผังพร้อมกันไม่เกินจำนวนทางจอดที่ผ่านได้** ขบวนช่วงหลังของภารกิจจึงมาแบบ "หลัง n" ผู้เล่นช้าแค่ไหนสถานีก็ไม่เต็มจนค้าง
3. **ขบวนด่วนต้องไม่ออกไปขาที่มีขบวนสวนกำลังมา** ไม่งั้นต้องหยุดในทางจอดและได้ 60 โดยผู้เล่นไม่ได้ทำอะไรผิด ขบวนสวนให้มาแบบ "หลัง" ขบวนด่วน
4. **สายน้ำตกที่หนองปลาดุกใช้ท3 ทางเดียว** ขบวน A→C กับ C→A ต้องต่อกันเป็นลูกโซ่ "หลัง" เสมอ ห้ามใช้เวลาตายตัว

## 7. การตัดสินใจ

เจตอบรับข้อเสนอรอบแรกครบ 7 ข้อ (2026-10-12):
1. ท่ากิเลนไม่มีอินเตอร์ล็อก (era 0)
2. ใช้ด่านดาวสะสม 15 และ 24 (เดิม 12 และ 20 ปรับ 2026-10-19 ให้สัดส่วนเท่าเดิมหลังเพิ่มภารกิจห่วง)
3. หน้าเลือกสายเปิดเมื่อผ่านน้ำตก
4. หนองปลาดุกใช้แผงแตะต้นทาง-ปลายทาง (nx)
5. หนองปลาดุกย่อเหลือ 3 ขา ตัดขาสุพรรณบุรี สายใต้ย่อเป็นเส้นเดียวต่อขา
6. รถกลับหัวเองทั้งขบวนที่น้ำตก
7. ท่ากิเลนมี 3 ภารกิจ และจะเป็น 4 เมื่อมีห่วงใน M2

ควรเติมหนึ่งบรรทัดใน GDD ข้อ 5 เรื่องกติกาปลดล็อกสถานีในเส้นทางสอน (ข้อ 2–3) ผู้อำนวยการเกมเป็นคนแก้

เรื่องที่ยังเปิด:
- **เลขขบวน** ถ้าจะให้เที่ยวขึ้นเป็นเลขคี่ เที่ยวล่องเป็นเลขคู่ ต้องมีฟิลด์เลขขบวนในตารางขบวนแยกจากลำดับ (engine-dev) และเจต้องบอกว่าใช้เลขสมมุติช่วงไหน
- **ความยาก** บอทได้ 3 ดาวทุกภารกิจ เจลองเล่นแล้วบอกว่าขั้น 3–4 ควรยากขึ้นไหม
- **เวลารอสูงสุดของ np-3** ปรับจาก 35 เป็น 45 วิ เพราะแผง nx ต้องแตะ 2 ครั้งต่อเส้นทาง ผู้เล่นที่แตะ 3 วินาทีต่อครั้งแพ้ที่ 35

- `wp-token` "หลีกขบวนด้วยห่วง" วังโพ era 1 แทรกหลัง wp-1: สองขบวนสวนกัน ห่วงของขบวนสวนต้องคืนเครื่องก่อนขบวนเราจึงออกทางนั้นได้ (บอท 0:44)
- ทั้งสองมีการ์ด "รู้หรือไม่" (ฟิลด์ `card`) ขึ้นหลังชนะ แหล่งใน `data/sources.md` แถว E7
- ผู้เล่นที่เคยผ่านภารกิจหลังจุดแทรกแล้ว ภารกิจและสถานีที่เคยได้ดาวเปิดค้างไว้ (`unlockState`) ไม่ถูกล็อกย้อนหลัง
- ข้อ 7 เดิม "ท่ากิเลนมี 3 ภารกิจ และจะเป็น 4 เมื่อมีห่วงใน M2" ทำแล้ว

**เจตัดสิน 2026-10-19 (WP4):**
- เกณฑ์ ROADMAP M2 "บทสอนสถานีแรกจบใน 3 นาที" = บทสอนพื้นฐาน tk-1 + tk-2 รวมไม่เกิน 3 นาที (บอทเร็ว) จึงลด tk-1 เหลือ 2 ขบวน tk-2 เหลือ 3 ขบวน และเพิ่ม speed ท่ากิเลน (tk-1 54, tk-2 56, tk-token 58, tk-3 58) เทสต์อยู่ใน `test/namtok-test.mjs`
- ดาวปลดล็อก กาญจนบุรี 15 หนองปลาดุก 24 (สัดส่วนเท่าเดิม) ผู้เล่นเดิมไม่ถูกล็อกย้อนหลังเพราะ `unlockState`
- เปิดห่วงใน nt-1 และ nt-2 เพื่อทบทวนก่อนออกจากขั้น 2 ส่วน wp-2 wp-3 ยังไม่เปิด (บอทมือช้าต่ำกว่า 80%) เก็บไว้เป็นโหมดท้าทายภายหลัง
