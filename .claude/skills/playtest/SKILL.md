# เล่นทดสอบ

ให้ **qa-tester** ทำ:
1. `npm test` (บอททุกด่าน/ภารกิจ + เทสต์ sim/)
2. `npm run build` แล้วเปิด `dist/` ด้วยเซิร์ฟเวอร์ในเครื่อง
3. Playwright ภาพหน้าจอ 844×390, 1180×820, 1280×800 และ 390×844 (ต้องเห็นเวทีหมุนเป็นแนวนอน) ทั้งสว่างและมืด ทุกหน้าจอหลัก (หน้าแรก, แผนที่, สถานี, ตัวแก้ผัง)
4. ทดสอบการแตะจริงทั้งแนวนอน และตอนถือเครื่องแนวตั้งที่เวทีถูกหมุน 90°
5. สรุปเป็นตาราง ผ่าน/ไม่ผ่าน และแนบภาพที่มีปัญหา
