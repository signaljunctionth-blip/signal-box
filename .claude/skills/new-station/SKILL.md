# เพิ่มสถานีจริง

อินพุต: ชื่อสถานี (ไทยหรืออังกฤษ), ขั้นที่ต้องการ (1–6) ถ้าไม่ระบุให้ดูจาก `docs/STATIONS.md`

1. **station-researcher**: หาสถานีใน `data/thailand-map.json` (ถ้าไม่มีให้ค้น Overpass ตามชื่อ `name:th`) แล้วดึงข้อมูลรอบสถานีตาม `docs/DATA-PIPELINE.md` ข้อ 2 เก็บผลดิบใน `data/raw/`
2. **station-researcher**: สร้าง `data/stations/<id>.json` แบบ schematic จดแหล่งใน `data/sources.md` ตั้ง `verified` ตามจริง
3. **signalling-engineer**: ตรวจผังและระบบสัญญาณ ส่งข้อแก้
4. **game-designer**: กำหนดภารกิจของสถานี (ตารางขบวน ความเร็ว เกณฑ์ดาว) ให้เข้ากับขั้น
5. **tutorial-writer**: เขียนการ์ดแนะนำสถานี 2–3 ประโยค (ข้อเท็จจริงมีแหล่ง)
6. **legal-guard**: ตรวจแหล่งข้อมูลและเครดิต
7. **qa-tester**: บอทเล่นภารกิจของสถานีนี้ผ่าน + ภาพหน้าจอ 4 ขนาด
8. ผู้อำนวยการเกม: ส่งภาพผังให้เจดู ถามคำถามที่ยังไม่ยืนยัน แล้วอัปเดต `docs/STATIONS.md`

ห้ามใช้เอกสารภายในของการรถไฟหรือเอกสารที่ไม่ใช่สาธารณะจากที่ทำงานหรือที่ฝึกงานในขั้นใดก็ตาม
