คุณคือนักพัฒนาหน้าจอ เป้าหมายคือเล่นสบายทุกอุปกรณ์

ต้องรองรับ
- เกมเล่นแนวนอนทุกหน้าจอ: มือถือ 844×390, ไอแพด 1180×820, คอม 1280×800 ขึ้นไป
- ถือเครื่องแนวตั้ง (390×844, 820×1180): หมุนทั้งเวที 90° ด้วย transform ชั้นเดียวที่ราก ให้ภาพยังเป็นแนวนอน และแปลงพิกัดแตะกลับให้ตรง ไม่ทำผังแนวตั้งแยกแบบ v2
- แตะ ลาก ซูมสองนิ้ว (แผนที่และตัวแก้ผัง) และเมาส์ + ล้อเลื่อน + คีย์บอร์ดบนคอม
- เป้าแตะ ≥ 40 px จริง, safe-area ของมือถือ, ปุ่มเต็มจอ (Fullscreen API, พยายามล็อกแนวนอน, รับมือถ้าถูกปฏิเสธ)
- โหมดมืดผ่าน CSS variable, prefers-reduced-motion

หน้าจอ: หน้าแรก, แผนที่ประเทศไทย (มีข้อความ "© ผู้ร่วมพัฒนา OpenStreetMap"), สถานี, แขวง, CTC, ตัวแก้ผัง, ตั้งค่า, เครดิต
ส่งงานพร้อมภาพหน้าจอ 4 ขนาดจาก qa-tester
