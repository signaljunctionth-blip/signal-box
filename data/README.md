ไฟล์ใน `data/raw/` และไฟล์ที่แปลงมาจาก OpenStreetMap (เช่น `data/stations/*.json`, `data/thailand-map.json`) เป็น

- สัญญา ODbL ครอบเฉพาะข้อมูลในโฟลเดอร์นี้ที่มาจาก OpenStreetMap ไม่ครอบโค้ดเกมและฟอนต์
- ไฟล์ `data/stations/fictional-*.json` และ `data/levels/*.json` เป็นผังสมมุติและด่านที่ทีมเขียนเอง ไม่มีข้อมูลจาก OpenStreetMap จึงอยู่ใต้ข้อความสงวนลิขสิทธิ์ใน `LICENSE` ที่รากโปรเจกต์ ไม่ใช่ ODbL

- ดึงข้อมูลจาก Overpass ตอนพัฒนาเท่านั้น และห้ามใช้ `out meta` (จะได้ชื่อผู้แก้ไข OSM ติดมา)
- วันที่ดึง ขอบเขต และแหล่งอ้างอิงของแต่ละไฟล์จดไว้ใน `sources.md`

## รูปแบบไฟล์ `thailand-map.json` (แผนที่ประเทศของโหมดอาชีพ)

สร้างด้วย `node tools/build-map.mjs` จากไฟล์ดิบใน `raw/` (ถ้ามีไฟล์ดิบแล้วสคริปต์ไม่ดึงเครือข่ายซ้ำ) ห้ามแก้ไฟล์นี้ด้วยมือ
ขนาดราว 185 KB เกมโหลดไฟล์นี้ครั้งเดียว ไม่เรียกบริการแผนที่ใด ๆ ตอนเล่น

### พิกัดและการฉายภาพ
- ทุกจุดเป็น `[lon, lat]` องศา WGS84 (ลองจิจูดมาก่อน) "เส้น" คืออาร์เรย์ของจุด `[[lon,lat],[lon,lat],…]`
- `bbox` = `[minLon, minLat, maxLon, maxLat]` ครอบทุกจุดในไฟล์ (ปัจจุบัน `[97.35, 5.62, 105.66, 20.45]`)
- ตัววาดฉายภาพเอง (equirectangular ปรับ cos 13°):
  ```js
  const C = Math.cos(13 * Math.PI / 180);
  const k = Math.min(viewW / ((bbox[2] - bbox[0]) * C), viewH / (bbox[3] - bbox[1])); // px ต่อองศาละติจูด
  const x = (lon - bbox[0]) * C * k;
  const y = (bbox[3] - lat) * k;
  ```
  สัดส่วนกว้าง:สูงของทั้งประเทศ ≈ 0.546 (แผนที่ทรงตั้ง ต้องเลื่อน/ซูมบนจอแนวนอน)

### โครงสร้าง
| คีย์ | ชนิด | ความหมาย |
|---|---|---|
| `schema` | เลข | รุ่นของรูปแบบไฟล์ (ตอนนี้ 1) |
| `bbox` | `[4]` | ดูข้างบน |
| `fetched` | object | วันที่ของข้อมูล: `natural_earth` (วันที่ดาวน์โหลด), `natural_earth_version`, `osm_rail` และ `osm_namtok` (เวลาของฐานข้อมูล OSM ตอนดึง, UTC) |
| `credits` | object | `osm` และ `natural_earth` แต่ละตัวมี `text`, `url`, `license`, `covers` (คีย์ที่มาจากแหล่งนั้น) ส่วน `osm` มี `license_url` (ข้อความสัญญา ODbL 1.0) ด้วย **หน้าแผนที่ต้องแสดง `credits.osm.text` พร้อมลิงก์ `credits.osm.url` เสมอ** |
| `country.polygons` | เส้น[] | เส้นขอบประเทศ แต่ละตัวเป็นวงปิด (จุดแรก = จุดสุดท้าย) ตัวแรกคือแผ่นดินใหญ่ ที่เหลือคือเกาะ (เกาะเล็กกว่า 20 ตร.กม. ตัดออก) ใช้ระบายพื้นและวาดขอบ |
| `provinces.borders` | เส้น[] | เส้นแบ่งจังหวัด **เฉพาะส่วนที่อยู่ในแผ่นดิน** (ไม่ซ้ำกับขอบประเทศ) เป็นเส้นเปิด วาดเป็นเส้นบางทับพื้นประเทศ ไม่ใช่ polygon จึงระบายสีรายจังหวัดไม่ได้ |
| `provinces.labels` | object[] | 77 จังหวัด: `iso` (เช่น `TH-71`), `name_en`, `lon`, `lat` (จุดวางป้าย) **ไม่มีชื่อไทย** (ชื่อไทยใน Natural Earth ผิดหลายจังหวัด จึงไม่ได้เก็บ) |
| `lines` | object | ตารางสาย คีย์คือ id ของสาย: `northeast`, `north`, `south`, `maeklong`, `east`, `west` แต่ละตัวมี `name_th`, `short_th`, `name_en` ลำดับคีย์ = ลำดับที่ทีมจะสร้าง (docs/STATIONS.md) |
| `rail` | object[] | แนวทางรถไฟทั้งประเทศ (ดูด้านล่าง) |
| `landmarks` | object[] | สถานีใหญ่/ชุมทางสำหรับเป็นจุดอ้างอิงบนแผนที่ (ดูด้านล่าง) |
| `namtok` | object | เส้นทางสอนสายน้ำตกแบบละเอียด (ดูด้านล่าง) |

### `rail[]` แนวทางรถไฟทั้งประเทศ
```json
{"line":"northeast","also":["north"],"name":"ทางรถไฟสายเหนือ/ตะวันออกเฉียงเหนือ","km":30.6,"pts":[[100.5914,14.0611],[100.593,14.0506]]}
```
- `line`: id ของสายใน `lines` หรือ `null` ถ้า OSM ไม่มีชื่อ/relation ที่บอกสายได้ (ทางเลี่ยงเมือง ทางเข้าท่าเรือ ฯลฯ ให้วาดสีกลาง)
- `also`: มีเฉพาะช่วงที่หลายสายใช้ร่วมกัน (เช่น กรุงเทพ–ชุมทางบ้านภาชี) `line` คือสายแรกตามลำดับใน `lines` ไม่ได้แปลว่าสำคัญกว่า
- `name`: ชื่อทางใน OSM (อาจเป็น `null`) ใช้แยกทางแยกในสายเดียวกันได้ เช่น `สายกาญจนบุรี` กับ `สายสุพรรณบุรี` ใน `west`
- `km`: ความยาวของเส้นก่อนลดรายละเอียด
- `pts`: เส้นเปิด ทศนิยม 4 ตำแหน่ง (ราว 11 ม.) ลดรายละเอียดคลาดเคลื่อนไม่เกิน 30 ม.
- หนึ่งเส้น = หนึ่ง **แนวทาง** ไม่ใช่หนึ่งราง: รางคู่และทางขนานที่ซ้อนกันถูกรวมเหลือเส้นเดียว จึงใช้บอกจำนวนรางไม่ได้
- เส้นไม่ได้ต่อกันเป็นกราฟ ปลายเส้นที่ชุมทางอาจห่างกันได้ถึงราว 100 ม. ใช้วาดเท่านั้น อย่าใช้หาเส้นทาง
- ไม่รวมรถไฟฟ้าในเมือง (สายสีแดง, แอร์พอร์ต เรล ลิงก์), ทางที่กำลังก่อสร้าง และสายเด่นชัย–เชียงราย–เชียงของ (ยังไม่เปิดเดินรถ)
- ขอบเขต `west` ตอนนี้คือสายน้ำตกกับทางแยกสุพรรณบุรี ช่วงธนบุรี–หนองปลาดุกยังเป็น `south` ตามชื่อใน OSM (รอเจยืนยันขอบเขตสายตะวันตก)

### `landmarks[]` สถานีอ้างอิง
```json
{"name_th":"กรุงเทพอภิวัฒน์","name_en":"Krung Thep Aphiwat","kind":"station","lon":100.54171,"lat":13.80403,"lines":["northeast","north"],"osm":"https://www.openstreetmap.org/node/8986366369"}
```
- 48 แห่ง ชื่อตามแท็กใน OSM (`นครลำปาง`, `ปาดังเบซาร์ (ไทย)` เป็นชื่อใน OSM)
- `lines`: สายของแนวทางใน `rail` ที่อยู่ห่างหมุดสถานีไม่เกิน 150 ม. (อาจมีหลายสายที่ชุมทาง)
- ยังไม่มี `id` และ `tier` เพราะยังไม่ได้ตรวจ จะเพิ่มเมื่อทำผังสถานีแต่ละแห่ง

### `namtok` เส้นทางสอน
- `line`: `"west"`, `name_th`, `name_en`, `osm` (ลิงก์ relation ของสาย)
- `tutorial_route`: id สถานีเส้นทางสอน 5 แห่ง **เรียงตามลำดับในเกม** `["tha-kilen","wang-pho","nam-tok","kanchanaburi","nong-pla-duk-jn"]`
- `path`: เส้นเปิดเส้นเดียวจากย่านชุมทางหนองปลาดุกถึงสุดทางประธานที่สถานีน้ำตก 130.7 กม. ทศนิยม 5 ตำแหน่ง คลาดเคลื่อนไม่เกิน 3 ม. (ละเอียดกว่า `rail` ใช้ตอนซูมเข้า) จุดแรกอยู่ก่อนหมุดสถานีชุมทางหนองปลาดุก 0.58 กม.
- `extension`: ช่วงน้ำตก–น้ำตกไทรโยคน้อย 1.39 กม. ต่อจากปลาย `path` **ไม่อยู่ในเกม** (GDD ข้อ 5) วาดจาง ๆ หรือไม่วาดก็ได้
- `km_note`: คำอธิบายวิธีคิด `km`
- `stations[]`: สถานีและที่หยุดรถทุกแห่งบนสาย 32 จุด เรียงตาม `km`
  ```json
  {"id":"tha-kilen","name_th":"ท่ากิเลน","name_en":"Tha Kilen","kind":"station","lon":99.25723,"lat":14.04059,"km":97.74,"off_m":0,"osm":"https://www.openstreetmap.org/node/272303917","order":1,"tier":1}
  ```
  - `id`: ตัวพิมพ์เล็ก-ขีดกลาง ของสถานีเส้นทางสอน 5 แห่งคือชื่อไฟล์ `data/stations/<id>.json` ส่วน id ของสถานีอื่นสร้างจากชื่ออังกฤษใน OSM และยังเปลี่ยนได้
  - `kind`: `"station"` (9 แห่ง) หรือ `"halt"` (23 แห่ง) ตามแท็ก `railway` ใน OSM
  - `km`: ระยะตามแนวเส้นใน OSM นับจากหมุดสถานีชุมทางหนองปลาดุก **ไม่ใช่หลัก กม. ทางการ**
  - `off_m`: ระยะจากหมุดสถานีถึงแนวเส้น (เมตร)
  - `order` (1–5) และ `tier` (ขั้นความยากตาม docs/STATIONS.md): มีเฉพาะสถานีเส้นทางสอน 5 แห่ง
  - `beyond_terminus: true`: อยู่บน `extension` (น้ำตกไทรโยคน้อย) ไม่อยู่ในเกม
  - ถ้ำกระแซมีหมุด 2 จุดใน OSM (สองฝั่งสะพาน): `tham-krasae-bridge` และ `tham-krasae`

### ไฟล์ดิบที่ใช้
| ไฟล์ใน `raw/` | เนื้อหา | สัญญาอนุญาต |
|---|---|---|
| `ne-<วันที่>-admin0-th.geojson` | Natural Earth 1:10m Admin 0 เฉพาะประเทศไทย | สาธารณสมบัติ |
| `ne-<วันที่>-admin1-th.geojson` | Natural Earth 1:10m Admin 1 เฉพาะ 77 จังหวัด | สาธารณสมบัติ |
| `osm-<วันที่>-thailand-rail.json` | Overpass 1 คำขอ: `railway=rail` ที่ไม่มีแท็ก `service` ทั้งประเทศ, relation `route=railway` ของทางเหล่านั้น, สถานี/ที่หยุดรถ | ODbL 1.0 |
| `osm-2026-10-11-namtok-line.json` | Overpass 1 คำขอ: สายน้ำตกและบริเวณใกล้เคียง | ODbL 1.0 |

วันที่ในชื่อไฟล์เป็นวันที่ตามเวลา UTC สัญญา ODbL ข้างบนครอบส่วนที่มาจาก OSM (`rail`, `landmarks`, `namtok`) ส่วน `country` และ `provinces` มาจาก Natural Earth ซึ่งเป็นสาธารณสมบัติ เส้นขอบเป็นแนวโดยประมาณตาม Natural Earth ไม่ใช่เส้นเขตแดนทางการ

- **แท็กที่ติดมาในไฟล์ดิบ:** ไฟล์ดิบจาก Overpass เก็บแท็กของ OSM ตามที่ได้มา (เช่น `operator`, `network`, `website`, `wikidata`, `wikimedia_commons`, `source`) เป็นข้อมูล OSM ตามปกติภายใต้ ODbL ไม่ใช่ทรัพย์สิน (ภาพ โลโก้ เว็บ) ที่เกมนำมาใช้ เกมใช้เฉพาะพิกัด ชื่อสถานี ชนิดสถานี ชื่อสาย และรูปทรงราง
- **ถ้าไฟล์ดิบรางทั้งประเทศเกิน 5 MB:** สคริปต์จะตั้งชื่อ `*.big.json` ซึ่งไม่เข้า repo (ดู `.gitignore`) ในกรณีนั้นสิ่งที่เปิดเผยตาม ODbL ข้อ 4.6 คือวิธีแปลง ได้แก่ `tools/build-map.mjs` พร้อมคำขอ Overpass ในตัวแปร `OVERPASS_QUERY` ของสคริปต์ และไฟล์ที่แปลงแล้ว `thailand-map.json` (ตอนนี้ไฟล์ดิบ 4.96 MB ยังอยู่ใน repo)
- **Overpass:** รอบนี้ใช้ `overpass-api.de` เท่านั้น สคริปต์ไม่มี mirror สำรอง
